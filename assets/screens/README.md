# Screens

Terminal screenshots of `shoots`, generated by `scripts/capture-screens.tsx`
(`npm run build:screens`). Every one is a capture of real output — the Ink UIs
driven by keystrokes, the batch commands actually executed. Do not edit by hand.

| Screen | PNG | SVG | What it shows |
| --- | --- | --- | --- |
| `shell` | [shell.png](./shell.png) | [shell.svg](./shell.svg) | The interactive shell as it opens: wordmark, environment line, empty prompt. |
| `palette` | [palette.png](./palette.png) | [palette.svg](./palette.svg) | Typing "/" opens the command palette with live autocomplete. |
| `mentions` | [mentions.png](./mentions.png) | [mentions.svg](./mentions.svg) | Typing "@" completes real paths from the filesystem. |
| `run` | [run.png](./run.png) | [run.svg](./run.svg) | A real cull executed from the shell, output streamed into its scrollback. |
| `review` | [review.png](./review.png) | [review.svg](./review.svg) | Human-in-the-loop review of the uncertain shallow-DoF rescues. |
| `cull` | [cull.png](./cull.png) | [cull.svg](./cull.svg) | A real focus-aware cull run: per-frame scores and the summary line. |
| `rate` | [rate.png](./rate.png) | [rate.svg](./rate.svg) | Local CLIP scoring: stars and keywords written to sidecars. |
| `doctor` | [doctor.png](./doctor.png) | [doctor.svg](./doctor.svg) | Environment health check: tools and model provisioned under ~/.shoots. |
